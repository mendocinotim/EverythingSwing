# EverythingSwing Project

## Project Overview
This project processes Fred Hall's Swing Thing radio shows to create searchable, copyright-compliant content with AI-powered insights.

## Directory Structure
- **raw_audio/** - Original, unprocessed audio files
- **processed_audio/** - Audio files at various stages of processing
- **transcriptions/** - Text transcriptions of audio content
- **metadata/** - Show and segment metadata
- **summaries/** - Generated content summaries
- **training_data/** - LLM training materials
- **models/** - Trained models and configurations
- **code/** - Source code repository
- **configs/** - Configuration files
- **docs/** - Documentation
- **tools/** - Utility scripts and helpers

## Requirements
- MacWhisper for transcription
- LMStudio for model training
- Cursor for development
- Sortformer for audio processing
